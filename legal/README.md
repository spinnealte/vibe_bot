# Тексты юридических документов

Каталог задаётся в `.env` (`LEGAL_DOCS_DIR`, по умолчанию `legal/`). В git лежит только этот README,
сами тексты кладутся на сервер вручную по ssh.

## Имена файлов

`<type>_v<version>.html`, где `type` и `version` совпадают со строкой в таблице `legal_documents`:

| type | Документ |
|---|---|
| `privacy_policy` | Политика обработки персональных данных |
| `pd_consent` | Согласие на обработку персональных данных |
| `marketing_consent` | Согласие на получение рекламных рассылок |
| `offer` | Публичная оферта (для полного бота) |

Пример: `pd_consent_v1.html`.

## Новая версия документа

1. Положить файл с новой версией, старый не удалять (согласия ссылаются на конкретную версию).
2. Добавить строку в `legal_documents` с новой версией и `is_current = true`, у старой снять `is_current`.
